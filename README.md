# Sagun invitation design preview

Interactive visual review of Axis Studio's Nepali and English invitation designs.

[Download the Windows preview ZIP](./sagun-visual-preview.zip?raw=true)

1. Download the ZIP file.
2. In Windows Downloads, right-click the ZIP and choose **Extract All**.
3. Open `sagun-visual-preview.html` from the extracted folder.

Choose **Design**, **Your words**, or **The day** to edit the invitation and see changes immediately. **Save draft** downloads your edits, **Open draft** restores them, and **Print / PDF** exports a printable copy.

The preview runs locally with embedded fonts and artwork. Accounts, hosted invitation links, guest responses and payment reviews are provided by the full server application.

Third-party license notices and opening instructions are included in the ZIP.
