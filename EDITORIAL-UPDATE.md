# Editorial invitation update — 3 October 2026

The Axis floating header now contains invitation product navigation (Home, Templates, Pricing, Help, My invitations, Create invitation). The brand links home to this product; studio attribution remains in the footer. Mobile navigation uses a native modal dialog for focus containment and Escape dismissal.

All 16 invitation variants use two opening photographs with staggered, paired, rounded or letter-like compositions. The editor provides independent URL and upload inputs. Existing content without a second cover photograph uses a different gallery photograph, or an empty-photo placeholder. Data stays independent of template presentation. Both cover uploads are subject to ownership checks and remain private until a published snapshot references them.

Heavy perimeter frames and repeated large floral backgrounds were removed. Cultural artwork is a restrained cover/footer accent. Traditional typography now defaults to Tiro; Newa uses Anek. Other font choices remain available. This is a visual collection with shared content sections, not sixteen wholly independent guest journeys.

## Guest interaction

The opening button starts the couple's music inside the user gesture, when a track exists. Music never starts on page load. A discreet play/pause control remains available; switching tabs pauses audio. Browser playback rejection leaves the control ready for another tap. Demo invitations remain silent unless a track is supplied; no ChungDoi recording has been copied.

After opening, slow guided scrolling begins after 4.5 seconds. Touch, pointer interaction, wheel scrolling, keyboard use and hiding the tab cancel the automatic scroll. A single pause/resume control remains; speed and animation/still selectors were removed. Reduced-motion preferences disable automatic scrolling and decorative motion. Motion preference is detected locally, not inferred by an AI model. Legacy motion settings are retained in stored content for compatibility but are no longer presented as choices.

## Research and commercial judgment

[ChungDoi's official creation guide](https://chungdoi.com/help/create-online-wedding-invitation) describes a browser invitation reached through a shared link and music playing when the guest opens the card. Its [template collection](https://chungdoi.com/templates) presents complete invitations with photos, music, maps and gift QR codes. The supplied Lotus example provides the long-form visual reference. The new design uses original Axis assets and preserves the exclusion of RSVP and guest CRM.

This direction gives Axis a more focused product: strong photography, readable Nepali lettering and an effortless opening. Willingness to pay is still untested. Before charging, review the actual invitation on iPhone and Android, and put three curated designs in front of prospective couples rather than treating template count as proof of value.

## Validation

TypeScript and both local regression suites pass. Tests cover product navigation, two-photo markup across all template routes, second-photo persistence and ownership, draft media privacy, publishing, language preservation and SEO. The production build is checked separately before publication.

Fresh browser visual/interaction testing remains unavailable because of the browser URL policy restriction. Music playback, reduced-motion behavior, mobile focus behavior and automatic scrolling therefore still need a real-device check. Earlier screenshots are not evidence of this update.

Payments remain test adapters. The site retains its existing private audience and the custom domain is not connected by this update.
